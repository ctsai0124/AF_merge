# Microsoft Edge Add-ons 商店資訊（繁體中文）

## 名稱
AF → aftool 一鍵匯入

## 簡短說明（manifest description，132 字元內）
在「各機關學校用人費用管理資訊系統」按一下，自動取得校對清冊(A)並直接匯入 aftool 欄位排序系統，免下載、免拖檔。

## 詳細說明（Store listing → Description）
專為學校人事人員設計的小工具：在行政院人事行政總處「各機關學校用人費用管理資訊系統」（AF 系統）中，一鍵取得「校對清冊(A)」，直接送進「AF 用人費用欄位排序系統」（aftool，https://aftool.leotsai.me/）進行排序與比對。

使用方式
1. 登入 eCPA 人事服務網，開啟「AF:各機關學校用人費用管理資訊系統」，按「進入本系統」。
2. 進入「用人費用資料維護 → 資料校對及報表列印」頁面。
3. 按頁面右下角的「AF → aftool 一鍵匯入」按鈕（或工具列的 AF 圖示）。
4. 擴充功能會自動開啟「報表列印」、選擇「校對清冊(A)」、EXCEL 格式、人員類別「全部」，並填入 aftool 公版下載密碼，取得報表後直接匯入 aftool 分頁。
5. 兼辦多校時，切換右上角「兼辦機關」後再按一次，會沿用同一個 aftool 分頁。

隱私與安全
- 只在 fund.dgpa.gov.tw 與 aftool.leotsai.me 兩個網站運作，不要求「所有網站」權限，也不使用 cookie、下載、歷史紀錄等權限。
- 只有在您按下按鈕時才動作；不讀取或傳送帳號、密碼、cookie，不修改 AF 系統任何資料。
- 取得的報表只交給 aftool 分頁，不送往任何第三方；擴充功能本身不儲存任何資料，也沒有追蹤或廣告程式。
- 隱私權聲明：https://aftool.leotsai.me/privacy-extension

注意：需具備 AF 系統的公務帳號（經 eCPA 登入）才能使用；AF 系統開放時間為每日 7:00～19:00。
